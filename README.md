# 🚀 TaskFlow

A simple task management web application created for learning and practicing **Git, GitHub, and basic web development**.

## 📌 About The Project

TaskFlow is a beginner-friendly task manager where users can add, complete, and delete tasks.

The main purpose of this project is not to build a production-ready application, but to practice:

- Git commands
- GitHub workflow
- Branching
- Commits
- Pull requests
- Merge conflicts
- README documentation

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 View all tasks
- 🔍 Filter completed and pending tasks
- 💾 Store tasks locally

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Git
- GitHub
